If you want to discuss or ask for help with using the runtime, post in our [forum](https://talk.observablehq.com/) or [community Slack](https://observablehq.com/slack/join).

## Development

We use pnpm. To install dependencies:

```
pnpm i
```

To run tests with Mocha:

```
pnpm run test
```
